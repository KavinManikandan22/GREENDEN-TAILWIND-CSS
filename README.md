# GREENDEN-TAILWIND-CSS

# 🌱 Greenden Webpage

A modern, responsive website for **Greenden**, designed with **Tailwind CSS**.  
This project includes a landing page, product listing page, and contact form — all styled for clean UI and mobile‑first performance.

---

## 🚀 Features
- **Landing Page (`index.html`)**
  - Sticky responsive navbar with mobile toggle
  - Hero section with call‑to‑action buttons
  - About section with mission, suppliers, and support details
  - Best seller product showcase
  - Customer reviews section
  - Newsletter subscription form
  - Footer with contact info

- **Product Page (`product.html`)**
  - Search bar for filtering products
  - Responsive product grid with hover animations
  - Product details (name + price)
  - Footer with contact info

- **Contact Page (`contact.html`)**
  - Contact form with name, email, phone, and message fields
  - Basic client‑side validation
  - Responsive navbar toggle
  - Footer with contact info

---

## 🛠️ Tech Stack
- **HTML5**
- **Tailwind CSS v2.2.19**
- **JavaScript (for interactivity)**
